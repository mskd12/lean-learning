# Lean playground

Informal experiments from learning Lean: evaluation, functions, structures,
induction over Fibonacci numbers, propositional proofs, vectors over `ZMod 2`,
and a small one-time-pad model.

This directory intentionally favors a chronological scratchpad over polished
library organization. It uses Lean and Mathlib 4.32.2 independently of the
Aeneas projects.
